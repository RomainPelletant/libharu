Libharu on Zephyr
#################

Generate PDF documents on Zephyr with the standard libharu API. This guide
covers module setup, component configuration, memory requirements, sample
applications and PDF capture over a console connection.

For Zephyr toolchain and workspace setup, see
:external+zephyr:ref:`getting_started`.
For the upstream libharu API documentation, see the
`libharu wiki <https://github.com/libharu/libharu/wiki>`_.
